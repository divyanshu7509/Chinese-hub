# Chinese Hub – Chinese Restaurant Website

## About the Project

Chinese Hub is a Chinese restaurant website developed as part of a Web Development assignment. The website showcases Chinese cuisine, restaurant information, a food menu and contact details through an attractive and responsive design.

## Features

- **Home Page:** Introduction to Golden Dragon with an attractive hero section.
- **About Us:** Information about the restaurant and its food.
- **Food Menu:** Displays popular Chinese dishes with descriptions and prices.
- **Special Dishes:** Highlights the restaurant's signature meals.
- **Gallery:** Images of Chinese food and restaurant ambience.
- **Contact Section:** Restaurant contact information and location.
- **Responsive Design:** Works on desktop, tablet and mobile devices.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations and responsive layout
- JavaScript – Interactive elements and functionality

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the restaurant website.
